GLYPHSCAPE v1.0.0

  

    
GLYPHSCAPE is a local-first instrument for creating and observing evolving three-dimensional glyph worlds. The primary workflow is GENERATE → SHAPE → SIMULATE → OBSERVE → CAPTURE.

    

      
Navigation
In Orbit mode, drag to rotate, hold Shift and drag to pan, and use the wheel to zoom. Reset restores the default camera.

      
Editing
Inspect chooses a cell. Sculpt changes elevation. Paint changes moisture, temperature, vegetation, water, or fire. Each completed stroke is undoable.

      
Simulation
Play advances fixed world steps. Water redistributes, plants grow or decline, fire spreads and exhausts fuel, weather changes, and agents travel.

      
Privacy and storage
All processing occurs locally. No account, telemetry, advertising, behavioral tracking, or silent network transmission is included. Autosave uses local browser storage.

      
Keyboard
O Orbit · I Inspect · S Sculpt · P Paint · Space Play or pause · Ctrl/⌘ Z Undo · Ctrl/⌘ Shift Z Redo.

      
Backups
Use Project — JavaScript Object Notation (JSON) to move work between browsers or retain a durable copy outside local browser storage.
