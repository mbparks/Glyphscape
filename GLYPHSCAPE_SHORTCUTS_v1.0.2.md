# GLYPHSCAPE v1.0.2 — Controls and Shortcuts

## Rotate and navigate

| Input | Action |
|---|---|
| Left drag | Tumble through unrestricted yaw and pitch |
| Right drag | Roll the world |
| Alt/Option + left drag | Roll the world |
| Shift + left drag | Pan |
| Middle drag | Pan |
| Mouse wheel or trackpad scroll | Zoom |
| Double-click visible cell | Select and focus the cell |
| Left/Right Arrow | Yaw |
| Up/Down Arrow | Pitch |
| Alt/Option + Left/Right Arrow | Roll |
| Reset | Restore default yaw, pitch, roll, pan, and zoom |

All three rotation axes wrap continuously through 360 degrees.

## Tools

| Key | Tool |
|---|---|
| O | Orbit |
| I | Inspect |
| S | Sculpt |
| P | Paint |
| Escape | Return to Orbit mode or close the current non-recovery dialog |

## Project, simulation, and history

| Key | Action |
|---|---|
| Control/Command + S | Save current project |
| Space | Play or pause simulation |
| Control/Command + Z | Undo |
| Control/Command + Shift + Z | Redo |
| Control/Command + Y | Redo |

Shortcuts are suspended while the cursor is in an input, selection control, or text area.

## Project command distinctions

| Command | Result |
|---|---|
| New | Separate blank project with new identity and defaults |
| Load demo | Separate editable Highland Reach demonstration |
| Clear current world | Remove world content but retain project identity and generation controls |
| Reset simulation | Restore the stored simulation baseline while retaining project and camera |
| Stop | Pause without resetting |
| Delete saved project | Remove one selected library record |
| Clear all local data | Remove every GLYPHSCAPE-owned local project and preference record |
