# GLYPHSCAPE v1.2.2

GLYPHSCAPE is a local-first three-dimensional ASCII world generator, editor, simulator, explorer, and capture instrument.

## v1.2.2 note

This release fixes the v1.2.1 camera-framing regression that made newly generated worlds appear smaller and flatter by resetting the user's perspective Orbit composition. Generation now preserves deliberate perspective zoom and focus. Use **Frame** when you intentionally want to recenter and fit the complete world.

Open `GLYPHSCAPE_v1.2.2.html` in a modern browser. No account or backend is required.
