GLYPHSCAPE v1.0.2

  

    
GLYPHSCAPE is a local-first instrument for creating and observing evolving three-dimensional worlds rendered as animated American Standard Code for Information Interchange (ASCII) art. The primary workflow is GENERATE → SHAPE → SIMULATE → OBSERVE → CAPTURE.

    

      
Navigation
In Orbit mode, left-drag to tumble freely through 360° yaw and pitch. Right-drag or Alt/Option-drag to roll. Hold Shift or middle-drag to pan, and use the wheel to zoom. Reset restores the default orientation.

      
Editing
Inspect chooses a cell. Sculpt changes elevation. Paint changes moisture, temperature, vegetation, water, or fire. Each completed stroke is undoable.

      
Simulation
Play advances fixed world steps. Water redistributes, plants grow or decline, fire spreads and exhausts fuel, weather changes, and agents travel.

      
Privacy and storage
All processing occurs locally. No account, telemetry, advertising, behavioral tracking, or silent network transmission is included. Versioned projects use Indexed Database storage with a local active-project fallback, strict validation, and a session-only recovery mode.

      
Keyboard
O Orbit · I Inspect · S Sculpt · P Paint · Arrow keys rotate · Alt/Option + ←/→ roll · Space play or pause · Ctrl/⌘ Z undo · Ctrl/⌘ Shift Z redo.

      
Backups and recovery
Use Project — JavaScript Object Notation (JSON) for durable backups. Destructive project actions can create a recovery copy first, and unreadable stored data is preserved until you explicitly replace or delete it.
