GLYPHSCAPE v1.2.3




GLYPHSCAPE is a local-first instrument for creating and observing evolving worlds in a true three-dimensional scene rendered as animated American Standard Code for Information Interchange (ASCII) art. The primary workflow is SEED → SHAPE → POPULATE → SIMULATE → OBSERVE → CAPTURE.




Navigation
Use Orbit for unrestricted yaw, pitch, and roll, Free Fly to move through the scene, and the Top or Iso presets for stable map and diorama views. Drag to look, right-drag or Alt-drag to roll, and double-click terrain to focus it.


ASCII vision
Shaded maps scene light to a glyph ramp. Semantic preserves recognizable material and entity symbols. Hybrid combines semantic identity with luminance, depth fade, and detected silhouettes. Automatic resolution preserves character proportions; adaptive resolution temporarily reduces work during movement or expensive renders, then automatically returns to full detail after the scene settles.


Editing
Inspect, Sculpt, and Paint now use terrain ray casting against the continuous three-dimensional surface. Each completed editing stroke remains one undoable transaction.


Simulation
Play advances fixed world steps. Water redistributes, plants grow or decline, fire spreads and exhausts fuel, weather changes, and agents travel.


Privacy and storage
All processing occurs locally. Schema version 4 projects use Indexed Database storage with a local active-project fallback, strict migration from earlier projects, and a session-only recovery mode. No account, telemetry, advertising, tracking, or silent network transmission is included.


Keyboard
O Orbit · T Top · V Isometric · I Inspect · S Sculpt · P Paint · Arrow keys rotate · Alt/Option + ←/→ roll · W A S D fly · Q/E down/up · F focus · Space play/pause · Ctrl/⌘ Z undo.


Backups and recovery
Use Project — JavaScript Object Notation (JSON) for durable backups. Destructive project actions can create a recovery copy first, and unreadable stored data is preserved until you explicitly replace or delete it.
